 AI Expense Tracker & Prediction System

 Overview

This project is an AI-based expense tracker that helps users manage their daily expenses and predict future spending using simple machine learning techniques.

It allows users to add, categorize, and analyze expenses efficiently.

---

 Features

- Add and manage daily expenses
- Automatic expense categorization (Food, Travel, Shopping, Bills, etc.)
- Expense prediction using AI/logic
- Dashboard to view reports
- Simple and user-friendly interface

---

 Technologies Used

- Python
- HTML, CSS
- SQLite (Database)
- Flask (Backend)

 How to Run the Project

1. Install Python
2. Install required libraries:

pip install flask

3. Run the application:

python app.py

4. Open browser and go to:

http://127.0.0.1:5000

---
 How It Works

- User enters expense details
- System analyzes description
- Automatically assigns category
- Stores data in SQLite database
- Predicts future expenses based on previous data
